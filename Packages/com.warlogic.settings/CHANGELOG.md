# Changelog

## [0.1.0] - 2026-09-06

- Initial release: `SettingsTab`, `ISetting<T>`/`Setting<T>` with Immediate/OnSave apply modes, concrete setting types (float, int, bool, enum, string) with optional min/max, validation and enable-condition delegates, custom enum option labels via `OptionLabel`, `SettingsRegistry`, `ISettingsStore` + `PlayerPrefsJsonSettingsStore`.
